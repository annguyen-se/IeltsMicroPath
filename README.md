# IELTS Master Studio (IeltsTrain) 🎓🚀

> Nền tảng học và luyện thi IELTS thích ứng toàn diện 4 kỹ năng (Reading, Listening, Writing, Speaking) kết hợp Ngữ pháp học thuật và Hệ thống ghi nhớ từ vựng ngắt quãng (Spaced Repetition System - Leitner 5-Box).

---

## Tính Năng Nổi Bật

### 1. Bản Đồ Lộ Trình Học Tập Thích Ứng (Curriculum Roadmap & DAG)

- **5 Cấp độ chuẩn quốc tế (Level 0 $\rightarrow$ Level 4)**:
  - **Level 0 (Band 0–4.0 / CEFR A1–A2)**: Khởi động & Mất gốc (ngữ âm IPA cơ bản, thì hiện tại đơn, từ vựng đời sống).
  - **Level 1 (Band 4.0–5.5 / CEFR A2–B1)**: Nền tảng 4 kỹ năng (Listening Section 1–2, câu ghép/câu phức, đoạn văn đọc hiểu ngắn).
  - **Level 2 (Band 5.5–6.5 / CEFR B1–B2)**: Chiến thuật phòng thi (TFNG, Matching Headings, Task 1 báo cáo số liệu, Task 2 bố cục chuẩn).
  - **Level 3 (Band 6.5–7.5 / CEFR B2–C1)**: Nâng cao điểm số (Bài đọc học thuật 700+ từ, bẫy từ đồng nghĩa, đảo ngữ & mệnh đề quan hệ).
  - **Level 4 (Band 7.5–8.0+ / CEFR C1)**: Thành thạo tối đa (Xử lý đề thi khó nhất, tư duy phản biện Task 2, từ vựng C1/AWL bậc cao).
- **Trục thời gian chặng học liên hoàn (Milestone Timeline Rail)**: Hiển thị tuần tự từng bước (`BƯỚC #1`, `BƯỚC #2`...), trực quan hóa trạng thái _Đã thành thạo (Mastered)_, _Sẵn sàng học (Ready)_ và _Đang khóa (Locked by prerequisites)_.
- **Ghép đôi 2 chiều Lý thuyết & Thực hành**: Thẻ Lý thuyết đi kèm bài Thực hành liên kết và ngược lại. Học viên có thể tra cứu lý thuyết bất cứ lúc nào trong khi làm bài tập mà không mất tiến trình.

---

### 2. Phòng Luyện Đọc IELTS Reading (Đủ 11 dạng bài chuẩn Cambridge)

1. **Multiple Choice** (Đơn & Nhiều đáp án `mcq`, `mcq-multiple`).
2. **Identifying Information** (True / False / Not Given `tfng`).
3. **Identifying Writer’s Views** (Yes / No / Not Given `ynng`).
4. **Matching Information** (`matching-info`).
5. **Matching Headings** (`matching-headings` với danh sách tiêu đề loại trừ).
6. **Matching Features** (`matching-features`).
7. **Matching Sentence Endings** (`matching-endings`).
8. **Sentence Completion** (`sentence-completion`).
9. **Summary / Note / Table / Flow-chart Completion** (`summary-completion` đục lỗ nội dòng).
10. **Diagram Label Completion** (`diagram-label` kèm tính năng phóng to Lightbox modal).
11. **Short-answer Questions** (`short-answer` có giới hạn từ `NO MORE THAN X WORDS`).

- **Bảng đối chiếu Paraphrase**: Hiển thị bảng từ đồng nghĩa đối chiếu câu hỏi $\leftrightarrow$ bài đọc sau khi nộp bài.

---

### 3. Phòng Luyện Nghe IELTS Listening (4 Section chuẩn thi)

- **Trình phát Audio Sticky**: Hỗ trợ Play/Pause, tua lùi/tiến 10s, điều chỉnh tốc độ (0.8x, 1.0x, 1.25x), tắt/bật âm.
- **Dạng bài nghe thực tế**: Form Completion (điền biểu mẫu thông tin cá nhân, số điện thoại, giá tiền), Map/Plan Labelling (sơ đồ khuôn viên trường), Multiple Choice.
- **Audio Tape Script**: Mở khóa toàn văn bản ghi âm kèm giải thích bẫy phát âm (`ERR_PHO`) và bẫy gây nhiễu (`ERR_DIS`).

---

### 4. Phòng Viết Luận IELTS Writing Studio

- **Task 1: Academic Report (7 dạng bài chuẩn thi)**:
  - Line graph, Bar chart, Pie chart, Table, Process, Map, Mixed charts.
- **Task 2: Academic Essay (5 dạng bài chuẩn thi)**:
  - Opinion (Agree/Disagree), Discussion (Both views), Advantages/Disadvantages, Problem/Solution, Two-part question.
- **12 Chủ đề IELTS chuyên sâu**: _Technology & AI, Environment, Education, Work & Careers, Society, Health, Crime & Law, Transport, Culture, Economy, History..._
- **Bộ đếm từ realtime & Đồng hồ đếm ngược** (20 phút / 40 phút).
- **Bộ chấm tự động theo 4 Band Descriptors**:
  1. _Task Achievement / Task Response (TR)_
  2. _Coherence & Cohesion (CC)_
  3. _Lexical Resource (LR)_
  4. _Grammatical Range & Accuracy (GRA)_
- **Luyện dịch câu vi mô (Sentence Translation Drill)**: Luyện dịch 100 câu học thuật qua 12 cấu trúc ngữ pháp trọng tâm.

---

### 5. Phòng Thi Nói IELTS Speaking Studio (3 Part Simulator)

- **Part 1 (4–5 phút)**: Phản xạ với câu hỏi quen thuộc đời thường.
- **Part 2 (3–4 phút)**: Cue Card + đồng hồ 60 giây chuẩn bị (kèm ô ghi chú nhanh) + 2 phút ghi âm trả lời.
- **Part 3 (4–5 phút)**: Thảo luận học thuật mở rộng chuyên sâu.
- **Ghi âm trực tiếp (`MediaRecorder API`)**: Bấm thu âm, hiển thị sóng mic và phát lại câu trả lời trực tiếp trong trình duyệt.
- **Khung tự đánh giá theo 4 tiêu chí Speaking**: _Fluency & Coherence, Lexical Resource, Grammatical Range, Pronunciation_.

---

### 6. Hộp Nhớ 5 Ngăn Leitner (Spaced Repetition System) & Mistake Vault

- **Kho từ vựng học thuật Oxford 3000 & AWL**: Tra cứu IPA, định nghĩa, ví dụ, collocations, word family.
- **Thuật toán Leitner 5 ngăn**: Tự động tính toán chu kỳ ôn tập ngắt quãng (Box 1 $\rightarrow$ Box 5) để đưa từ vựng vào trí nhớ vĩnh viễn.
- **Hầm chứa bẫy lỗi sai (Mistake Vault)**: Tự động gom các câu làm sai và phân loại theo 5 nhóm lỗi:
  - `ERR_LEX`: Lỗi từ vựng, ngữ nghĩa.
  - `ERR_PHO`: Bẫy âm thanh, phát âm, nuốt âm.
  - `ERR_SYN`: Lỗi cú pháp, ngữ pháp, trật tự từ.
  - `ERR_DIS`: Bẫy thông tin gây nhiễu (distractor).
  - `ERR_LOG`: Lỗi suy luận logic, nhầm lẫn False vs Not Given.

---

### 7. Pipeline Tự Động Hóa Dữ Liệu (Seed Pipeline Engine)

- **Tự động gọi LLM (9Router / Gemini / OpenAI)**: Sinh toàn bộ từ vựng, bài đọc, transcript, câu hỏi theo ma trận Levels $\times$ Topics $\times$ Skills.
- **Bộ kiểm tra nghiêm ngặt (`pipelineValidator.js`)**: Bắt buộc bằng chứng (`evidence.text`) và từ khóa (`vocabAnchors.text`) phải là **chuỗi con nguyên văn (verbatim substring)** trong bài đọc để triệt tiêu hoàn toàn ảo giác AI (hallucination).
- **Tối ưu tốc độ cao**:
  - Ghi batch bằng `bulkWrite()` vào MongoDB (giảm 95% latency mạng).
  - Tự động bỏ qua các bài đã có (`Skip Existing`).
  - Chạy song song nhiều skill và topic cùng lúc.

## Hướng Dẫn Cài Đặt & Khởi Chạy

### 1. Yêu cầu môi trường

- **Node.js** phiên bản `>= 18.0.0`
- **npm** hoặc **yarn**
- **MongoDB** (Local hoặc MongoDB Atlas URI)

### 2. Cài đặt Backend

```bash
cd IeltsTrain/backend
npm install

# Tạo file .env từ mẫu .env.example
cp .env.example .env
```

Cấu hình các biến trong file `backend/.env`:

```env
PORT=5000
NODE_ENV=development
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret_key_min_32_characters
CLIENT_URL=http://localhost:5173

# (Tùy chọn) Cấu hình gateway AI nếu muốn chạy pipeline tự động sinh dữ liệu:
NINEROUTER_BASE_URL=http://localhost:20128/v1
NINEROUTER_API_KEY=your_api_key
```

Chạy backend server:

```bash
npm run dev
# Server lắng nghe tại http://localhost:5000
```

### 3. Cài đặt Frontend

Mở một terminal mới:

```bash
cd IeltsTrain/frontend
npm install
npm run dev
# Ứng dụng chạy tại http://localhost:5173
```

## Hướng Dẫn Sử Dụng Seed Pipeline (Sinh Dữ Liệu Tự Động)

Pipeline nằm trong thư mục `backend/src/scripts/seedPipeline.js`:

### Chế độ 1: Nạp trực tiếp từ file JSON bundle

```bash
# Kiểm tra dữ liệu (dry run - không lưu DB):
node src/scripts/seedPipeline.js --file src/data/sample_bundle_test.json --dry-run

# Nạp thật vào database:
node src/scripts/seedPipeline.js --file src/data/sample_bundle_test.json
```

### Chế độ 2: Sinh tự động theo Level & Topic mục tiêu

```bash
# Sinh bài học kỹ năng Reading cho chủ đề "Technology" ở Level 2:
node src/scripts/seedPipeline.js --level 2 --topic "Technology" --skill reading

# Sinh trọn bộ 6 kỹ năng cho chủ đề "Environment" ở Level 3:
node src/scripts/seedPipeline.js --level 3 --topic "Environment" --skill all
```

### Chế độ 3: Chạy tự động duyệt toàn bộ ma trận (Full Matrix)

```bash
node src/scripts/seedPipeline.js
# Hệ thống tự động duyệt qua các Level 0 -> 4, song song 2 topic và 3 skill cùng lúc.
# Tự động bỏ qua các topic/skill đã hoàn thiện trong database.
```
